Maison Tia is a high-end luxury jewelry website focused on ethical diamonds (lab-grown) and Beldi silver.

**Technical Stack:**
- Framework: Next.js 16, React 19
- Styling: Tailwind CSS v4
- Palette: Obsidian, Gold, Ivory, Muted

**Current Implementation State (v3 - Cinematic Experience):**
- Architecture: Next.js 16 / React 19 / Tailwind v4.
- Engine: Lenis Smooth Scroll + GSAP Frame Scrubbing (Canvas).
- Narrative Flow: Intro Sequence $\rightarrow$ FrameScrubbing Cinema $\rightarrow$ Dual Universe Split (Or/Diamant vs Argent Beldi) $\rightarrow$ VIP Call to Action.
- Design: "The Apple Standard" - absolute black (#020504), high-contrast gold, minimal typography, and cinematic transitions.

**Pending Work / Goals:**
- Asset Pipeline: Process Instagram videos into optimized frame sequences via FFMPEG.
- Integration: Finalize the a-symmetry of the Dual Universe interactions.
- Performance: Optimize Canvas rendering for 4K displays.
