### ❌ Common Error: `mvn command not found`
**Why:** Maven is not installed by default on the OS.
**How to fix:** Install via Homebrew (`brew install maven`) or use Maven Wrapper (`./mvnw`).

### ❌ Common Error: Vite Dependency Resolution / Path Aliases
**Why:** Using `@/` aliases in React without configuring `tsconfig.json` and `vite.config.ts`.
**How to fix:** 
1. Install `vite-tsconfig-paths`.
2. Add the plugin to `vite.config.ts`.
3. Define `baseUrl: "."` and `paths: { "@/*": ["./src/*"] }` in `tsconfig.app.json`.

### ❌ Common Error: Missing Frontend Packages
**Why:** Dependencies like `react-router-dom` were used in code but not added to `package.json`.
**How to fix:** explicitly run `npm install <package-name>`.
